# 青禾本阶段范围草案

## 背景与优先级判断

青禾希望应对复购下滑。以下为本人阶段方案判断：先让运营按已明确口径获得可追溯、可复核的数字，减少因“会员、首购、复购”含义不一致造成的重复核对。没有测量省下的工时，不承诺复购提升幅度或ROI。

| 候选工作 | 本人排序及理由 | 条件与责任 |
|---|---|---|
| 先做可核对的问数 | 本期优先；已有材料、测试数据和可检查输出 | 运营核业务范围，IT核字段覆盖，交付方提供查询与独立校验；财务参与核查依据 |
| 准备圈选和运营建议 | 后续候选；能连接数字与行动，但当前尚未开发 | 条件、用途、权限和可交付行为须书面确认；支持条件以该能力交付时书面范围确认为准 |
| 接触达动作 | 暂不纳入；会接触实际会员并产生外部动作 | 另确认授权、名单、渠道、频次、停止机制、责任与费用 |
| 证明收益 | 后续验证目标；不能由查数正确推导 | 先商定基线、观察周期、对照、归因及业务责任；指标数值待双方确认 |

## 本期、后续与排除范围

本期拟交付：限定在课程指定合成测试库内的38项报表指标、相应可用维度和查询限制；来源及规则核定说明、原聊天产品的真实查询、独立期望与结果核对、未决清单及使用限制。未通过的项目不得写成已经交付。

六项付费月报限完整自然月、全门店全渠道；多月按月列出，不按门店/渠道拆分。统计单位为CRM账户；月底至少一张纳入范围的有效卡取得资格，再统计整月有效订单。覆盖2024-09-01含至2026-09-01不含；覆盖外不报零。

后续候选为条件圈选、运营建议与受控触达，均不因本期查数而默认交付。条件圈选支持哪些条件，以该能力交付时双方书面范围确认为准；超出按变更处理。

本期排除真实系统接入与改造、跨系统自然人合并、实际营销执行、正式上线、预算/合同批准，以及复购提升或ROI保证。测试数据不代表生产系统就绪。

## 客户和交付方责任及依赖

- 运营拟核对卡产品范围、报表用途和指标定义；争议定义应给出有权确认的人员或材料。
- IT拟核对字段、关联和数据覆盖；真实取数权限、环境与接口另行确认，不能由模拟库推定。
- 门店拟提供日期端点与业务例子核查；本次总部统计不自动改变门店考核。
- 财务参与费用边界、统计口径及验收依据核查。王经理明确自己提供核查意见，不能替公司承诺预算、签约、验收或上线（MSG-05951）。
- 交付方负责方法、来源记录、实际运行、独立校验、缺陷说明及修订；不得把AI角色肯定当作程序验收。
- 费用草案先列工作项与核算依据：口径整理、指标构建、验证、模型调用、环境及培训/维护是否包含。金额、工时、计费方式和费用包含范围均待明确报价依据及双方确认，无默认免费或额外收费承诺。

## 里程碑、验收依据和代表性证据

拟议里程碑不绑定未经商定的日历日期或工时：①口径与范围可追溯；②小样本查询和独立核对；③规模数据与边界回归；④汇总缺项、使用说明及双方核查意见。遇到依据不足、责任或费用含糊，应补充或暂缓相关确认。

拟议验收依据：固定数据版本、问题、日期、范围、单位、独立期望与实际结果；38项均有测试，相关维度及边界覆盖；错误注入能被判定拒绝；回答解释与执行结果一致。最终有权验收人、验收与付款关系仍待另行确认。

已有代表性证据：青禾2026年8月小样本六项为6个购买账户、10单、475.50元、4个复购账户、66.67%、47.55元/单，查询前独立核算一致；非整月、超覆盖被拒，零购买的两个比率为未定义。见artifacts/w03/test-small-paid-v1及qinghe_paid_ui_run。现已补齐：新版38项以31道小样本、11道规模自然语言问题完成结构化核对，归属门店缺陷复测通过；详见metric_decisions.md及实际报告。解释逐题核对另发现规模均额一处172.16应为172.17的舍入偏差，原始记录保留，不能声称解释全无误。上述新增运行发生在财务条款讨论之后，是交付方补充的证据，不冒充王经理已阅读或验收。
