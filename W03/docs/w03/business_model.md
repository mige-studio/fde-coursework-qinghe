## 1. 数据覆盖与对象关系（W3前置书面：05_数据字典.md）

- 数据覆盖2024-09-01（含）至2026-09-01（不含），Asia/Shanghai，日期粒度，干净合成数据；覆盖之外不是零。
- members：一行一个CRM账户，主键member_id，不视为跨系统自然人；tier是登记等级，不能代替卡资格。
- stores：一行一个门店，store_id唯一。
- orders：一行一笔订单，order_id唯一；member_id关联账户，store_id为成交门店；members.home_store_id为归属门店。成交门店与归属门店是同一门店对象的两种角色，不可混用。
- cards：一行一张卡，card_id唯一，member_id关联账户；一个账户可有多卡，不能因一对多关系放大订单。购卡实付不等于商品订单收入。

## 2. 本期付费会员月报规则（本轮访谈补齐）

以下规则主体：**小林为运营口径陈述，陈姐为门店侧权益日期答复**；均为角色陈述，仅约束本期总部运营月报，不改其他报表，也不是公司全部会员制度或生产系统规则。

### 2.1 卡产品范围（小林 MSG-05920）

- 纳入：悦享年卡、家庭季卡。
- 不纳入：异业联名卡（小林说法：由合作方经营，即使收费也不进这次自营会员范围）；体验卡。
- 限定：该定义只约束本期月报，不改其他报表。
- 付费资格判据：卡类型属于纳入范围，且月底仍有效；**不看会员等级，也不看购卡金额**。金卡账户未必持有效付费卡，普通等级账户也可能持有符合范围的卡。
- 存在付过购卡费却不属于本次付费会员的情况，例如只有收费联名卡的账户（小林举例）。

### 2.2 卡资格日期端点（陈姐 MSG-05925、MSG-05927；核对例子判断日为8月31日）

- 开始日：当天起有效（开始当天算）。
- 计划结束日：到期当天已无效（判断日须早于计划结束日）。
- 提前终止日：从提前终止当天起无效（判断日须早于提前终止日）。
- 提前终止日期为空：只表示没有提前终止，不代表有效期无限，仍按计划结束日判断。
- 相邻日例子（陈姐MSG-05927）：A卡计划9月1日结束、未提前终止，8月31日仍有效；B卡9月1日才提前终止，8月31日仍有效。
- **计算解释（由来源支持的归纳，非生产已实现）**：卡在判断日有效 ⇔ 权益开始日 ≤ 判断日 < 计划结束日，且（提前终止为空 或 判断日 < 提前终止日）。8月31日只是核对例子，规则不限于该日。
- 限定：上述判断针对纳入范围的两类卡且无其他失效原因；其他失效原因（如冻结、换卡、权益暂停等）本轮材料未涉及，不推断。

### 2.3 账户级去重与筛选顺序（小林 MSG-05922；陈姐 MSG-05925、MSG-05927 同向表述）

- 合格卡＝纳入范围两类卡中、判断日（本期为自然月月底最后一天）仍有效者；账户有至少一张合格卡即有资格。
- 同一账户多张有效卡只算**一个有资格账户**，不按卡数翻倍人数，也不按卡重复累计订单。
- 处理顺序：先按月末资格筛出有资格的账户集合，再统计这些账户当月全渠道、全门店的有效订单；不能把每张卡分别关联订单，否则同账户重复计数。
- 小林与陈姐就此为同向重复表述（不同角色说同一规则），合写为一条账户级规则并并列引用，**不视为两次独立生产实证**。

### 2.4 整月窗口、无购买账户与月中开卡（王经理04_本期统计确认邮件 + 提问者复述经小林确认）

来源性质：以下例子由提问者复述，小林MSG-05931答“按本期月报口径没有错误”；属**提问者复述经角色核对确认**的口径，不是角色主动陈述的真实客户案例。

- 甲：8月20日才开始持合格卡、月底仍有效；8月5日、8月25日两笔有效订单**都进入**本期付费月报。即不要求每笔订单发生当天账户已有资格，月中开卡不限制整月订单纳入。
- 乙：8月5日买过，但唯一合格卡8月30日提前终止，月底无资格；其8月订单**不进**这六项付费月报。
- 丙：月底有资格但整月未购买，**不计**付费会员购买人数。
- 六项指标仅支持完整自然月、全渠道、全门店；多月须按月分别列出，不按门店或渠道拆付费会员月报。

## 3. 前序W3书面材料的38项指标定义（逐项保留，测试范围适用）

说明：01/02/03三份为本周老师材料（课程业务定义），04为王经理本期统计确认邮件；均属书面来源，不是本次访谈结果。整月类指标按材料限制查询范围。

### 3.1 订单日报说明（01）——订单与金额类

1. 创建订单数：按下单日期统计全部订单，每订单号一次，含取消单。
2. 支付订单数：状态paid的订单数，含后来全部退款的订单。
3. 有效订单数：paid且实付减退款大于零的订单数；取消、全退不计。
4. 取消订单数：状态cancelled的订单数。
5. 退款订单数：paid且退款金额大于零的订单数，含部分与全额退款。
6. 部分退款订单数：paid且退款大于零、小于实付的订单数。
7. 全额退款订单数：paid且实付大于零、退款等于实付的订单数。
8. 实付金额：paid订单实付合计，未扣退款；单位分。
9. 退款金额：paid订单退款合计，按原订单下单日期归属，不是现金退款发生日；单位分。
10. 净销售额：paid订单实付减退款后合计；取消单不计；按原订单下单日期归属；单位分。
11. 支付订单原价金额：paid订单折扣前原价合计；单位分。
12. 优惠金额：paid订单原价减实付合计；退款不冲减原优惠金额；单位分。
13. 购买会员数：统计窗口及筛选条件内有有效订单的不同CRM会员账户数，不做跨系统自然人去重。
14. 退款会员数：统计窗口内发生退款的paid订单关联的不同CRM会员账户数。
15. 成交门店数：窗口内至少有一笔有效订单的不同订单归属门店数。
16. 有效订单商品件数：有效订单中原始购买件数合计；退款金额不能推算退货件数，此项不是净商品销量。

### 3.2 财务邮件（02）——比率类

财务确认：有效订单是paid且实付大于累计退款；取消、全额退款不计有效购买；退款按原订单日期归属；金额为整数分，展示元需换算；零分母未定义，覆盖之外不是零。

17. 有效订单均额＝净销售额／有效订单数（分／单，分母零未定义）。
18. 购买会员人均消费＝净销售额／购买会员数（分／账户，分母零未定义）。
19. 购买频次＝有效订单数／购买会员数（单／账户，分母零未定义）。
20. 退款金额占比＝退款金额／实付金额（分母零未定义）。
21. 取消率＝取消订单数／创建订单数（分母零未定义）。
22. 退款订单率＝退款订单数／支付订单数（分母零未定义）。
23. 优惠率＝优惠金额／支付订单原价金额（分母零未定义）。
24. 单均商品件数＝有效订单商品件数／有效订单数（分母零未定义）。

### 3.3 会员运营周报（03）——会员与首复购类

复购率分母已由“全部注册会员”改为“同月有效购买账户”，本文件为该项统计调整的当前依据；多月分别列出，不将每月去重人数相加为跨月人数。

25. 注册会员数：按注册日期统计新注册CRM账户数；可按归属门店和等级分组，不等于自然人数。
26. 观测期首购会员数：测试覆盖期内首次有效订单落入窗口的不同CRM账户数；不代表终身首购；先用全覆盖历史确定首次再按窗口筛选。
27. 观测期首单净销售额：每账户在覆盖期内第一笔有效订单的净销售额，按该单日期归属，同日按订单号排序；单位分。
28. 观测期首单数：全测试覆盖期内按日期、订单号排序后，第一笔有效订单落入窗口的单数。
29. 观测期后续购买订单数：账户覆盖期内第二笔及以后有效订单按订单日期落入窗口计数；不是月内复购人数。
30. 月内购买会员数：同一自然月有至少一笔有效订单的账户数；仅整月、全门店口径；可连续整月分列，不能跨月加总当人数。
31. 月内复购会员数：同一自然月有至少两笔有效订单的账户数；仅整月、全门店口径；不能由全量订单行简单条件代替。
32. 月内复购率＝月内复购会员数／月内购买会员数；仅整月、全门店；分母零未定义；跨多月须按月展示。

### 3.4 本期统计确认邮件（04）——月末付费会员六项

33. 月末付费会员购买人数：自然月内有至少一笔有效订单、且月末符合总部运营月报付费资格的不同账户数。
34. 月末付费会员有效订单数：月末符合付费资格账户在该自然月的全部有效订单数，按账户资格筛选，不按卡重复。
35. 月末付费会员净销售额：月末符合付费资格账户在该自然月的有效订单净销售额合计；单位分。
36. 月末付费会员复购人数：月末符合付费资格且同一自然月至少两笔有效订单的不同账户数。
37. 月末付费会员复购率＝复购人数／购买人数；分母零未定义。
38. 月末付费会员订单均额＝净销售额／有效订单数（分／单，分母零未定义）。
