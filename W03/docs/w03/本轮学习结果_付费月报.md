# 第三周：从访谈规则到可核对的青禾月报

本轮已经把付费会员规则用到实际产品，Edge 中查到了青禾 2026 年 8 月月报。六项结果与查询前独立核算一致。这是课程小样本的验证，第三周全部练习尚未结束，作业未提交。

## 第三周在练什么

前面的5轮是两场模拟访谈中的5次问答：小林3轮、陈姐2轮。访谈补齐材料没写明的规则；接下来是让产品按规则查数、检查结果，最后把可交付范围写成工作说明书（SOW）。

| 环节 | 实际做的事 | 业务上要看懂什么 |
|---|---|---|
| 核对来源 | 将两份本人访谈与老师材料归并，检查AI提取遗漏 | AI整理不等于业务事实，重要条件必须有原话 |
| 固定规则 | 两类卡、日期端点、账户去重、月末资格和整月订单 | “付费会员”须写成能判断每个账户是否纳入的条件 |
| 先算答案 | 用原始小样本逐账户、逐订单独立核算 | 先知道应得什么，再让产品回答，不能照产品答案改预期 |
| 产品问数 | 生成38项指标，通过结构检查，加载青禾后实际查询 | 能运行不等于算对；本轮先验证其中六项付费月报 |
| 核对结果 | 检查数字、日期、范围、单位、解释和不支持的情况 | 要同时证明“该答时答对”和“不能答时不编” |

## 8月月报：独立核算与实际产品一致

范围：2026-08-01至2026-09-01，不含结束日；全门店、全渠道；教学小样本。

| 指标 | 独立核算 | Edge实际结果 |
|---|---:|---:|
| 月末付费会员购买人数 | 6个账户 | 6个账户 |
| 有效订单数 | 10单 | 10单 |
| 净销售额 | 475.50元 | 475.50元 |
| 复购人数 | 4个账户 | 4个账户 |
| 复购率 | 4÷6≈66.67% | 66.67% |
| 订单均额 | 475.50÷10=47.55元/单 | 47.55元/单 |

月底有资格的账户其实有8个，只有6个有当月有效购买，所以购买人数不能填8。M00003、M00017没有有效订单，排除在购买人数之外。

M00001有两张合格卡，但只算一个账户、两笔订单，净销售额280元；不能因为卡有两张而翻倍。同样，月中开卡但月底有效的账户，开卡前发生的当月有效订单也纳入本期报表。

金额在原数据中以“分”保存，47550分展示为475.50元。这里的66.67%仅是合成样本月报结果，不代表青禾真实复购率，也不能说明我们的项目提升了复购。

## 还检查了什么

实际问数共4道测试题，全部符合事前期望；另在Edge实际提交了六项月报问题并核对网页结果。

- 2026年8月六项：全部与独立核算一致。
- 8月10日至20日：明确不支持，因为这组六项要求完整自然月。
- 2026年9月：明确超出数据覆盖，未冒充0。
- 2024年9月：有数据覆盖，但没有有效购买；人数、订单、金额为0，复购率和订单均额为“未定义”。

生成过程保留了两次失败。第一次两条引用不逐字一致；第二次仍有一条引用错误，审查又发现首单排名及空月份粒度问题。修订学生方法后重新生成，第三次来源、粒度、12项维度可达性和38指标编译检查通过，未手改生成SQL来冒充方法成功。

独立核算及判定程序的7项测试也通过，包含多卡去重、日期端点、整月窗口、零分母和错误单位/数值/范围拒绝。测试通过只说明已覆盖的情况，不能代替全周验收。
