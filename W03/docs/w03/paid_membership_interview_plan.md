# W03付费会员规则补访提纲

2026-11-17，依据用户“先把付费会员规则要补问的问题准备一下…再在Edge里帮我访谈”。本轮仅课程模拟补访和整理，不提交作业，不推进SOW批准。

已知材料：本期统计邮件明确月末资格、当月全部有效订单、完整自然月、全渠道全门店、多月逐月列出；数据字典仅说明字段，不裁定卡类型及日期端点。访谈角色陈述作为来源，不能冒充真实生产数据核验。

| 组 | 开放问题及追问 | 为什么问 |
|---|---|---|
| 产品范围 | 悦享年卡、家庭季卡、异业联名卡、体验卡分别是否纳入总部月报？依据是什么？有付钱但不纳入的情况吗？ | 先确定账户范围，不能凭卡名、付款或会员等级猜 |
| 日期边界 | 开始、计划到期、提前终止当天分别算不算？空的提前终止日期怎样理解？用8月31日举例 | 把模糊的有效期转为可执行日期判断 |
| 多卡与资格 | 同一账户多张卡、一张有效一张失效、同月续卡如何算？银卡金卡能否代替资格？购卡费用与订单收入是否分开？ | 避免按卡重复账户和订单，防止混淆不同业务对象 |
| 复述与例证 | 结合月中开卡、月底终止、月末仍有效举例复述，请指出错误；谁能核查实际门店日期及记录？ | 发现误解，找跨角色核对点；不让对方代写作业 |

先访小林，根据回答向陈姐核对门店权益实际处理；不预设未确认答案。每角色2场，每场12条，保存额度。王经理SOW访谈留到有条款和证据时。若角色明确不知道，记录待核实对象，不反复逼问。
