# 本机运行配置修正

## [2026-11-14] 本机标签请求错误进入系统代理

- 原因：Python自动读取macOS系统代理，同一本机标签地址默认连接返回502，直接连接返回预期404（不存在的动作）；外部模型调用正常。
- 影响：首次正式验证通过分析、退款说明、澄清、缺数据和只读检查后，在标签HTTP查询中断。不是已经证明标签执行成功。
- 修复方案：只在本实践启动器进程内保留外部代理路由，并将127.0.0.1和localhost排除代理。不改系统设置或老师业务源码。
- 自测结果：完整真实模型11项重新运行全部通过；页面标签确认后生效，撤销后显示不存在、版本2。
- 证据：artifacts/learning/first_attempt_local_proxy_error保留失败前证据；artifacts/w01为完整复测结果。首次异常为API_HTTP_502。
- 可能风险与建议：只验证了当前本机环境；其他机器或供应商需重新验证。回退可使用老师原入口与明确的环境配置。

依据：https://docs.python.org/3/library/urllib.request.html （getproxies、ProxyHandler、no_proxy）。
